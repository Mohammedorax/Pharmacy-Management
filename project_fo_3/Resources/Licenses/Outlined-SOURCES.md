# Local UI resources

AntdUI is pinned to NuGet 2.4.11; target asset `lib/net46/AntdUI.dll` is compatible with the existing net472 application.

Outlined SVGs are unmodified files from ant-design/ant-design-icons at commit
`7f2516ac91226d2b41f93b35cb5197c8d94f7189`, directory `packages/icons-svg/svg/outlined`.
Source: https://github.com/ant-design/ant-design-icons/tree/7f2516ac91226d2b41f93b35cb5197c8d94f7189/packages/icons-svg/svg/outlined
Their MIT license is included as `AntDesignIcons-MIT.txt`.

AntdUI Apache-2.0 license is included as `AntdUI-Apache-2.0.txt`.
License source: https://github.com/AntdUI/AntdUI/blob/bcf7d4bfc8c13a85f9378143e92e05f0e0ae1e57/LICENSE

Icons are embedded in the application. Runtime icon loading requires no network or account.
