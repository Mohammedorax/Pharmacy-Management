# اعتماد فواتير Excel أو حفظها للمراجعة

الاختيار الافتراضي في شاشة الاستيراد هو **اعتماد مباشر**. بعد قراءة الملف ومعاينته يختار المستخدم فاتورة واحدة ويعتمدها؛ تمر عبر عملية البيع أو الشراء الحالية، فتُسجل الفاتورة وحركة المخزون والقيد المرتبط بها ضمن معاملة العملية. لا تُعتمد بقية فواتير الملف تلقائيًا. يُحفظ مع الاعتماد مفتاح النظام المصدر ورقم فاتورته لمنع تكرار اعتماد المستند نفسه.

الخيار الثاني، **حفظ كمسودة**، يحفظ فواتير الملف للمراجعة دون تغيير المخزون أو القيود أو الأرصدة. عند اعتماد مسودة بعينها لاحقًا تمر عبر عملية الفاتورة نفسها، ثم تنتقل حالة المسودة إلى «معتمدة». لذلك لا يوجد مسار «سجل تاريخي للعرض فقط» في هذه المرحلة.

يُرفض الاعتماد إن لم تستطع عملية الفاتورة الحالية تمثيل البيانات بأمان، مثل كميات أو أسعار كسرية لا تدعمها الجداول الحالية، أو طريقة سداد/ضريبة غير مدعومة في المسار المستورد. يمكن إبقاء هذه البيانات كمسودة للمراجعة، لكن حفظ المسودة لا يعني أن اعتمادها مضمون. ينبغي تصحيح المصدر أو توسيع عقد الفاتورة واختباره قبل الاعتماد.

## التحقق والحدود

- اختبارات المجال تتحقق من مرحلتي المعاينة والمسودة وربط الاعتماد بعمليات الفواتير دون اتصال بقاعدة البيانات.
- اختبارات QA السابقة غطت اعتماد بيع مستورد مباشرة، ومن مسودة، ومنع تكرار المصدر، والإلغاء وإعادة المخزون؛ واختبارات الشراء المتاحة تتحقق من تراجع المعاملة عند فشلها. لا تُعد هذه الأدلة إثباتًا لكل أصناف ملفات العملاء أو كل طرق السداد.
- محاكاة FlaUI تختبر وضوح الخيارين وتبديلهما بلوحة المفاتيح بالعربية والإنجليزية، دون كتابة في قاعدة البيانات.
- قبل إتاحة اعتماد ملف كامل بضغطة واحدة، يلزم تحديد سياسة الفشل الجزئي لكل فاتورة، وعرض نتيجة كل مستند وإتاحة إعادة المحاولة الآمنة؛ يبقى الاعتماد الحالي فاتورة واحدة في كل مرة.
