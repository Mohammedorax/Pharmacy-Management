# ترحيلات قاعدة البيانات

هذه الترحيلات مخصصة **لقاعدة اختبار مستعادة فقط**. لا تشغّلها على قاعدة تشغيل أو قاعدة باسم عام؛ كل ترحيل يفحص أن اسم القاعدة ينتهي بـ `_test` أو `_qa` أو `_sandbox`.

ترتيب التنفيذ الحالي:

1. جهّز القاعدة الأساسية بواسطة `scripts/Initialize-PharmacyDatabase.ps1` أو التطبيق.
2. استعد نسخة احتياطية واستخدم قاعدة اختبار ذات اسم واضح.
3. ثبّت المخطط التجاري عبر `project_fo_3.exe --install-commercial-schema <verified-backup.bak>`.
4. شغّل مشغّل الترحيلات الرسمي. يسجل كل ملف ببصمة SHA-256 ولا يعيد ملفاً مسجلاً ببصمة مختلفة.

```powershell
.\scripts\Apply-CommercialMigrations.ps1 -ServerInstance '.' -DatabaseName 'PharmacyManagement_qa' -Environment Qa -VerifiedBackupPath 'C:\backups\verified-pharmacy.bak'
```

المشغّل ينفذ `RESTORE VERIFYONLY` لملف النسخة، ويرفض قاعدة لا ينتهي اسمها بـ`_test` أو `_qa` أو `_sandbox` والمتعارضة مع البيئة المختارة. لا يثبت أو يستعيد النسخة بنفسه، ولا يشكل نجاحه دليلاً على اختبار استعادة؛ يجب توثيق الاستعادة الفعلية منفصلة.

`0003_saudi_feature_settings.sql` يضيف إعدادات مزايا السعودية وسجل تدقيق append-only. `0004_commercial_migration_registry.sql` ينشئ سجل بصمات الترحيلات ويأخذ قفل SQL يمنع تشغيل ترحيلين بالتوازي. لا يفعّل أي منهما البيع التجاري أو فاتورة أو رصد أو نفيس؛ جميعها تبدأ `Disabled` ويجب ضبطها من شاشة «المعايير السعودية» داخل التطبيق على بيئة الاختبار.

`Apply-SaudiFeatureSettingsMigration.ps1` موقوف عمداً ولا يُستخدم. المشغّل الرسمي أعلاه هو المسار المدعوم الوحيد؛ فهو يطلب نسخة احتياطية واسم بيئة منضبط وينفذ الترحيلات بترتيبها.

لا تُعدّل ملفات الترحيل المعتمدة. أضف ملفاً جديداً مرقماً عند الحاجة، وحدّث مصدر التطبيق المقابل في `CommercialSchema.cs` داخل نفس التغيير.


ترحيل 0023_voucher_request_identity.sql يضيف RequestId وRequestCurrencyCode للسندات مع فهرس فريد مرشح. تبقى السندات السابقة بلا هوية (NULL)، ولا تُستنتج هوية من رقم السند أو المبلغ. الطلب الثابت يتطلب لقطة عملة ويُرفض قبل أي كتابة إذا غاب المخطط؛ الاستدعاءات القديمة لا تعتمد على الأعمدة الجديدة. مخطط الإنشاء الأساسي في Database.cs يطابق الأعمدة والفهرس للقواعد الجديدة فقط. لا ينفذ فتح التطبيق هذا الترحيل تلقائيًا. ربط محرر السند والاستعادة وقراءة الحالة وقبول SQL/التنافس مستقل ولم يقبل بعد.
